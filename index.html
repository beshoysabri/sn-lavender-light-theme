Lavender Light

A light theme with a lavender accent, the daytime twin of Lavender — and the whole app set in Inter.

v2.7.2

Install

https://beshoysabri.github.io/sn-lavender-light-theme/ext.json
  1. Open the Standard Notes desktop app → Preferences → Plugins
  2. Paste the link under Install Custom Plugin, at the bottom
  3. Pick Lavender Light from the Appearance menu

Use the desktop app for the install: the web app refuses plugin links from any self-hosted theme. Installed themes sync with your account, so it reaches the web app from there.

Pair it with Lavender

Install Lavender too, then turn on Preferences → Appearance → Use system color scheme and pick Lavender Light as the Automatic Light Theme and Lavender as the Automatic Dark Theme. Standard Notes then follows your OS between the two. That choice is stored per device, so set it once on each.

The whole app, in Inter

Super

Lavender, in daylight

A pastel can't carry text on white — Lavender's #a79ef4 is 2.4:1 there — so the accent keeps its hue and deepens to #6d61d1. The softness moves into the washes: selected notes and tags, selected text, the scrollbar.

Every grey is Lavender's, mirrored: the same contrast from the base, on the other side of it.

Code keeps its monospace face. That rule is listed after the app-wide one, so it wins at equal specificity:

pre, code, kbd, samp, pre *, code *,
[class*='code-' i], [data-lexical-code]

If this paragraph renders in Inter, the woff2 files resolved over Pages. This page loads them by relative path because a browser fetches it directly; the theme names the same files by absolute URL, because Standard Notes inlines theme CSS and a relative path would resolve against the app's own origin.

Notes

Desktop and mobile need Inter installed on the device. The desktop app sets default-src 'self' blob: with no font-src, so it refuses to download any webfont — a data: URI included. A font already installed needs no download, so it just works: get Inter, install it, restart the app. Without it you still get the colours, with the system font.

A mirror of Lavender. Each grey sits at the same contrast from the base as its twin in the dark theme: the #252525 sidebar becomes #f5f5f5, #2a2a2a borders become #eeeeee, and the #eeeeee text becomes #2a2a2a — 14.4:1 on its base in both. Hover greys are a step lighter than an exact mirror, so the selection stays the loudest thing in a list.

Selection is a lavender wash, not a grey bar. Standard Notes paints the selected tag and the selected note with the colour it also uses for hover. Here hover stays grey and the selected row gets an 18% lavender tint, as in Lavender — with the sidebar label in the darkened #5446c9, which reads at 5.0:1 on that tint where the accent itself would manage 3.6:1.

The accent is deep enough that text on it is white again (4.9:1), as in native Light — primary buttons, the new-note button, the Daily view's date tiles. Like the Copy button above.

The Daily notebook uses the app's danger token for today's date and the create-note button, which reads red on a lavender theme. Those specific elements are repainted with the accent — destructive controls stay red.

Inter carries no Arabic or CJK glyphs — those scripts fall through to the next family in the stack rather than rendering as boxes.
